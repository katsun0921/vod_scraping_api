# ルーティン用プロンプト

> 対象: Claude のルーティン（スケジュール実行）に貼り付けるプロンプト
> 設計の背景: [routine-discovery.md](./routine-discovery.md)
> 最終更新: 2026-08-07

ルーティンは Claude Code の `/schedule` から**人間が設定する**（AIからは起動できない）。
以下のプロンプトをそのまま登録する。

---

## ■ 共通の前提

どちらのルーティンも、リポジトリ `katsun0921/vod_scraping_api` で動く。
成果物は `news_bot/routine_data/` に固定名で上書きし、**PR を作成して終わる**。
シートへの反映・Slack通知・WP投稿は、PR マージ後に GitHub Actions が行う。

**PR は自動マージしない。** 人間のレビューが1次承認にあたる。

---

## ■ 劇場公開ルーティン

- **推奨スケジュール**: 毎週金曜 09:00 JST（Actions の `theater_discover` は月曜だったが、
  ルーティン方式では対象期間の起点に合わせる）
- **出力先**: `news_bot/routine_data/theater_latest.json`

### プロンプト

```text
このリポジトリの news_bot/routine_data/theater_latest.json を更新するタスクです。

## 対象期間の決め方

今日の日付を基準に「直近の金曜日」を求め、その日から7日間（金曜〜翌週木曜）を対象期間とします。
今日が金曜ならその日が起点です。土日に実行された場合は翌週の金曜が起点になります。

対象期間を求めたら、まずその開始日と終了日を明示してください。

## 調べること

対象期間に日本国内の映画館で劇場公開（初公開）される映画を Web 検索で調べてください。

以下は必ず守ってください。

- 事実情報のみを集めること。あらすじ・紹介文・レビューなどの文章は一切含めない
  （著作権に配慮するため。KatsumaScore は AdSense 掲載サイトです）
- 公開日が対象期間内で、日付が確認できた作品のみを含める
- 公開日が確認できない作品は含めない（推測で日付を埋めない）
- 再上映・リバイバル上映・特別上映は含めない（初公開のみ）
- 複数の情報源で確認できた作品を優先する。1つの情報源しか無い場合はメモに残す
- **金曜公開だけを調べて終わりにしない。** 日本の劇場公開は金曜が基準日だが、
  土曜以降に公開される作品もある。対象期間の**全曜日（金・土・日・月・火・水・木）**に
  ついて公開作品が無いか確認すること

## 出力形式

news_bot/routine_data/theater_latest.json を以下の JSON 配列で上書きしてください。

[
  {
    "title": "邦題",
    "release_date": "YYYY-MM-DD",
    "distributor": "配給会社名",
    "official_url": "公式サイトURL"
  }
]

- distributor / official_url が不明な場合は空文字 "" にする
- 対象期間に該当作品が見つからない場合は空配列 [] を書く

## 最後にすること

1. 変更を新しいブランチにコミットする（ブランチ名: routine/theater-YYYY-MM-DD）
2. PR を作成する。タイトルは「劇場公開情報 YYYY-MM-DD〜YYYY-MM-DD（N件）」
3. PR 本文には以下を書く
   - 対象期間
   - 見つけた作品の一覧（タイトル・公開日・配給・情報源のURL）
   - 情報源が1つしか無かった作品があればその旨
   - 判断に迷った点があれば明記する

PR はマージしないでください。人間がレビューして承認します。
```

## ■ VOD配信ルーティン

- **推奨スケジュール**: 毎週水曜 09:00 JST（Actions の `vod_discover` が木曜のため、
  その前日に PR を用意してレビュー時間を確保する）
- **出力先**: `news_bot/routine_data/vod_latest.json`

### プロンプト

```text
このリポジトリの news_bot/routine_data/vod_latest.json を更新するタスクです。

## 対象期間の決め方

今日の日付を基準に「翌週の月曜日」を求め、その日から7日間（月曜〜日曜）を対象期間とします。

対象期間を求めたら、まずその開始日と終了日を明示してください。

## 調べること

対象期間に日本国内の以下の VOD サービスで新たに配信開始される映画・ドラマ・アニメを
Web 検索で調べてください。

対象サービス: Netflix / Amazon Prime Video / U-NEXT / Disney+ / Hulu / DMM TV

以下は必ず守ってください。

- 事実情報のみを集めること。あらすじ・紹介文・レビューなどの文章は一切含めない
  （著作権に配慮するため。KatsumaScore は AdSense 掲載サイトです）
- 各 VOD サービスの公式サイトを自動巡回（スクレイピング）してはいけません。
  規約上禁止されています。Web 検索の結果として得られる情報のみを使ってください
- 配信開始日が対象期間内で、日付が確認できた作品のみを含める
- 配信開始日が確認できない作品は含めない（推測で日付を埋めない）
- 既に配信中の作品は含めない（新規配信開始のみ）
- 各作品の配信ページ（タイトルURL。例: Netflixなら `netflix.com/jp/title/...`、Prime Video
  なら該当作品の視聴ページ）を必ず Web 検索で特定して `url` に記載すること。ニュース記事や
  プレスリリースのURLでは代用しない。Web 検索の結果から配信ページのURLが特定できない作品は
  含めない（`url` を空文字のまま出力しない）

## 出力形式

news_bot/routine_data/vod_latest.json を以下の JSON 配列で上書きしてください。

[
  {
    "title": "邦題",
    "title_orig": "原題",
    "service": "netflix",
    "available_from": "YYYY-MM-DD",
    "availability_type": "見放題",
    "category": "映画",
    "url": "配信ページの公式URL"
  }
]

- service は次のいずれかの文字列を厳密に使う（表示名ではなくこのキー）:
  netflix / amazon_prime_video / unext / disney_plus / hulu / dmm_tv
- availability_type は 見放題 / レンタル / 購入 / 独占 のいずれか
- category は 映画 / ドラマ / アニメ のいずれか
- title_orig / availability_type / category が不明な場合は空文字 "" にする
- url は必須。配信ページが特定できない作品は一覧に含めない（詳細は上記「調べること」参照）
- 対象期間に該当作品が見つからない場合は空配列 [] を書く

## 最後にすること

1. 変更を新しいブランチにコミットする（ブランチ名: routine/vod-YYYY-MM-DD）
2. PR を作成する。タイトルは「VOD配信情報 YYYY-MM-DD〜YYYY-MM-DD（N件）」
3. PR 本文には以下を書く
   - 対象期間
   - 見つけた作品の一覧（タイトル・サービス・配信開始日・情報源のURL）
   - サービス別の件数
   - 判断に迷った点があれば明記する

PR はマージしないでください。人間がレビューして承認します。
```

## ■ レビュー時の確認ポイント

PR レビューが1次承認にあたる。以下を見る。

| 観点 | 見るところ |
|---|---|
| **実在するか** | 情報源URLを開いて作品が実在するか。AIは実在しない作品を出すことがある |
| **日付が正しいか** | 公開日・配信開始日が情報源と一致するか |
| **期間内か** | 対象期間外の作品が混ざっていないか（`in_range()` でも弾かれるが、多いならプロンプトの問題） |
| **曜日の偏り** | 劇場公開で金曜の作品しか挙がっていないか（土曜以降の公開作品を取りこぼしている疑い） |
| **サービスキー** | VOD の `service` が6つのキーのいずれかか（不正な値は取り込み時にスキップされる） |
| **あらすじが無いか** | 事実情報以外が混ざっていないか（著作権配慮） |

**疑わしい行は PR 上で削除してからマージする。** 取り込み後にシートから消すより手戻りが少ない。
